# IntervueX Styles

Each stylesheet contains page/feature-specific CSS:
- global.css: common layout, forms, buttons
- navbar.css: navigation
- home.css: landing page
- auth.css: login/register/auth pages
- dashboard.css: user dashboard
- jobs.css: job listing/details
- profile.css: profile/resume
- recruiter.css: recruiter pages
- admin.css: admin pages
- interview.css: interview/test UI
- compiler.css: coding compiler
- notifications.css: notification UI

index.css imports all styles so the application loads them from one entry point.
